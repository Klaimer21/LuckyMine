# Фоны и поле

В проекте лежат фоны зон `background_0.jpg` … `background_6.jpg` (1080×1920; 0 каменоломня, 1 медные пещеры, 2 железные жилы,
3 золотые залежи, 4 кристальная пещера, 5 магма, 6 ядро). Их рисует `tools/make_backgrounds.py` из `tools/backgrounds.html`
(правьте цвета и детали в `ZONES` и функциях рисования, затем запустите скрипт; нужны Python с playwright и Chromium).

## Свои картинки
Положите файл с тем же именем, и он заменит нарисованный: `background_N.png` или `.jpg` (png проверяется первым), общий
`background.png` / `.jpg` (для зон без своего файла), `field_N.png` — вид сверху на пол зоны (пропорции около 6.6 : 6.2, например
1024×960), общий `field.png`. Без `field_*` пол рисуется процедурно цветом зоны. Если файла для зоны нет, берётся общий.

Фон идёт позади стола: вертикальный, лучше тёмный по краям и снизу (там интерфейс). Игра сама добавляет плавный наплыв между
зонами, мягкую тень вокруг поля, пыль цвета зоны, затемнение сверху под счётчиком и лёгкое «дыхание» фона при ударах.
Рамка из брёвен и железные стойки остаются 3D.

## Фоны планет
`planetP_N.png` или `.jpg` — фон зоны N на планете P (planet1_N — Марс). Если файла нет, берётся фон Земли, окрашенный оттенком планеты.
Набор Марса рисуется командой `python3 tools/make_backgrounds.py --planet 1` (палитра `MARS` в `tools/backgrounds.html`).

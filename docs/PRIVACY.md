## По-русски

**Кто мы.** LuckyMine разрабатывает [ИМЯ РАЗРАБОТЧИКА]. Контакт для вопросов: [E-MAIL].

**Какие данные собирает игра.** Никакие. LuckyMine не требует аккаунта и не отправляет данные на серверы.

**Что хранится на вашем устройстве.**
- Сохранение игры (монеты, улучшения, достижения, время последнего запуска) в файле в хранилище приложения.
- Настройки (язык, качество графики, громкость, вибрация).

Эти файлы лежат только на вашем устройстве. Они удаляются при удалении игры или кнопкой «Сбросить прогресс»
в настройках. Игра может скопировать ваше сохранение в виде текстового кода в буфер обмена, только когда вы сами
нажмёте «Скопировать код сохранения»; вставка кода тоже выполняется только по вашему нажатию.

**Разрешения Android.** Вибрация (отклик на касания). Если в игре появится реклама, добавятся доступ в интернет и
к состоянию сети.

**Реклама и покупки.** В текущей версии рекламы и покупок нет (в игре есть заглушка для будущей рекламы за награду;
она ничего не загружает и никуда не отправляет). Если реклама будет добавлена, эта политика будет обновлена:
рекламная сеть сможет получать рекламный идентификатор устройства и некоторые технические данные, а вы сможете
отозвать согласие в настройках игры.

**Дети.** Игра не собирает данные ни о ком, в том числе о детях.

**Изменения.** Мы можем обновлять эту политику; актуальная версия публикуется по ссылке на странице игры в магазине.

## In English

**Who we are.** LuckyMine is developed by [DEVELOPER NAME]. Contact: [EMAIL].

**What data the game collects.** None. LuckyMine needs no account and sends no data to any server.

**What is stored on your device.**
- The game save (coins, upgrades, achievements, time of last launch) in a file in the app's storage.
- Settings (language, graphics quality, volume, vibration).

These files stay on your device only. They are deleted when you uninstall the game or press "Reset progress"
in Settings. The game copies your save as a text code to the clipboard only when you press "Copy save code";
pasting a code also happens only when you press the button.

**Android permissions.** Vibration (touch feedback). If ads are added later, internet and network-state access
will be added too.

**Ads and purchases.** The current version has no ads and no purchases (there is a placeholder for future rewarded
ads; it loads nothing and sends nothing). If ads are added, this policy will be updated: the ad network may receive
the device advertising ID and some technical data, and you will be able to withdraw consent in the game settings.

**Children.** The game collects no data about anyone, including children.

**Changes.** We may update this policy; the current version is linked from the game's store page.
